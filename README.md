# Digimon-inspired TAG & CREST Animated Cursors

Windows 11 cursor project, managed one cursor at a time.

## Goal
- One unified set of 17 cursor roles, including animated `.ani` assets.
- Digimon-inspired TAG & CREST designs, with eight crest motifs represented across the set.
- Prioritize practical hotspots, visibility, and correct animation over bulk generation.

## Folders
- `references/` — visual design references (only user-approved assets)
- `masters/` — approved still master images
- `frames/` — animation frame sequences
- `cursors/` — built `.cur` / `.ani` files
- `scripts/` — repeatable build and validation scripts
- `docs/` — decisions and test results

## Current status
Workspace created. **No design, master, or animated cursor has been approved or built yet.**
See [production status](docs/STATUS.md).

## Workflow
Discuss one cursor → approve still design → build frames → convert to ANI → test in Windows → commit.

Existing third-party example cursor files are reference material, not project output. Do not redistribute them without permission.
